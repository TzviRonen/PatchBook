    <h1>About <strong>PatchBook</strong></h1>
  </div>
  <article class="prose" markdown="1">

A collaborative technical analysis library for closed-source security patches.

Each report is generated by an automated system or a human researcher that
downloads patched and unpatched binaries, diffs them, identifies changed
functions, and writes a structured report covering the root cause, patch
mechanics, and exploitation primitives.

Researchers can upload new reports, suggest changes to existing ones, and vote
on report quality - creating a trustworthy, technically detailed single source
of truth for CVEs.

For suggestions of any kind, feel free to message me on
[LinkedIn](https://www.linkedin.com/in/tzvi-ronen/).
